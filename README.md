 Week 7 Assignment: My Notes & The Report Builder

This assignment demonstrates Python file handling, CSV reading, and report generation.

 Files

- my_notes.py – Writes, appends, reads, and counts notes in a text file.
- my_notes.txt – Stores the four notes created by my_notes.py.
- report_builder.py - Reads learner scores from a CSV file and generates a report.
- hubs.csv – Contains learner names, hubs, and scores.
- report.txt – Contains the generated learner report.

 What happens if "a" is changed to "w"?

The "a" mode appends new content without deleting existing notes. If it is changed to "w", the file is overwritten, so the first three notes will be erased and only the fourth note will remain.
